01 / THE IDEA

Reading should feel like
getting lost in a story.

MangaReader is a native Android app for people who want a focused way to read the manga and comics they already have. It puts your local library first, with a clean interface and tools that stay out of the way.

07 / QUICK ANSWERS

Good to
know.

A few details about MangaReader and how to get involved.

What is MangaReader?

MangaReader is a native Android application for reading local manga and comic archives, with library management and a focused reading experience.

Does it work offline?

The app is designed around offline-first, local reading. Online-connected integrations, such as AniList, naturally require a connection for their online features.

Where can I get the app?

Visit the GitHub repository for the current source code, build instructions, and any available releases. Add your official download link here once you have one.

How can I contribute or report a bug?

Open an issue in the GitHub repository with a clear description, steps to reproduce, and relevant device or Android-version details. Pull requests are welcome in line with the project's contribution guidance.

Does the app host or provide manga?

MangaReader is a reader for files you provide. This website does not offer manga downloads or host copyrighted reading material.
